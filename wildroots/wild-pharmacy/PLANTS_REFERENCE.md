# Wild Pharmacy — Plant Reference (13 stations)

Canonical names and data for the 13 hero plants, keyed to the 13-hour clock in
the Labyrinth. The truth source is `stations.json` (exported from
`wildroots/Apothecary_Index.xlsx`); this doc adds the **narration spellings** so
the auto-transcript (`audio/WildPharmacy_narration_anime.txt`) can be cleaned and
so UI copy never inherits Whisper's phonetic guesses.

> Origin note: of the 13, ten are SA-native. Gotu kola is Asian, rosemary
> Mediterranean, wormwood hedged (A. absinthium European vs native A. afra).
> Do NOT claim the 13 collectively South African.

| Hour | Canonical (common) | Latin | Also known | Heard in narration as | Part used | Key caution (the "minotaur") |
|---|---|---|---|---|---|---|

## The four-step loop (per station)

The narration names the intentional loop the maze teaches at every station:

1. **Identify** the true plant by its shape and shadow.
2. **Harvest** the correct part with gratitude.
3. **Extract** its potent gifts.
4. **Concoct** the remedy.

(`frames_anime/frame_005.png` is a clean "Learning Loop" diagram of these four
steps — earmarked for a help / how-to screen.)
